## 行为回归

- 导航：未注册/重复注册、创建失败回滚、根页返回、多实例、替换、重置、单实例复用、找不到目标页、栈满及命令队列满。
- 生命周期：before_show/before_hide 的当前页一致性、失败清理、1000 次往返后创建/销毁数量一致。
- 事件：系统优先、消费后停止、历史遍历、事件回调内排队及同步重入拒绝。
- 通信：未注入协议拒绝初始化、临时注入解码器、逐字节拆包、连续多帧、RX 队列满时保留待投递帧。
- 发送：暂不可写、短写分段保持、非法消息长度拒绝。
- 错误：不前进的解码器、输入缓冲耗尽、故障锁存及 reset。
- Linux：队列 close 唤醒等待线程、socketpair 非阻塞读写、对端断开和 MSG_NOSIGNAL。
- GUI 桥接：根页面创建前保留消息，页面就绪后由 GUI 定时器分发。

上述回归通过 AddressSanitizer + UndefinedBehaviorSanitizer 重跑，开启泄漏检测，未报告越界、未定义行为或内存泄漏。临时回归源码与测试可执行文件在验证完成后删除，未纳入提交。

## 最小通信案例验证（2026-10-09）

- `lak_comm_echo` 独立目标在严格编译选项下构建通过，没有编译或链接 LVGL。
- 普通 socketpair 收发与 `--fragment` 每次最多 2 字节读写均完成 PING/PONG 往返，退出码为 0。
- 两种运行模式经 AddressSanitizer + UndefinedBehaviorSanitizer 和泄漏检测验证通过。
- 案例编解码器验证了空行、半帧不消费、粘包逐帧提取、最大负载、超长行，以及分隔符负载、非零 id、输出容量不足和空参数的拒绝行为。
- 未知命令行参数返回 2；临时边界验证程序已删除。案例源码是正式使用说明的一部分，保留在 `examples/comm_echo`。

该案例在单线程内调度本地 socket，不覆盖真实 UART、远端 TCP、线程并发或 GUI 交互。
